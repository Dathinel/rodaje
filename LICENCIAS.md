# Licencias de las dependencias

Este archivo lista cada componente de terceros que Rodaje usa o planea usar, con su licencia verificada, la fuente donde se verificó y lo que esa licencia implica para un programa MIT que se entrega como ejecutable autocontenido. Se actualiza cada vez que se añade, quita o actualiza una dependencia. La última verificación se hizo el 9 de octubre de 2026 leyendo los metadatos de los paquetes en nuget.org y los archivos de licencia de cada repositorio.

Hay una diferencia importante entre dos tipos de dependencias. Las que se usan solo para compilar o probar, como xUnit, nunca salen del equipo de desarrollo: no se copian a `dist\` ni viajan con el programa, así que su licencia solo importa para el uso interno. Las que se redistribuyen dentro de `dist\`, como el runtime de .NET o las DLL de FFmpeg, imponen obligaciones al entregar el programa, y sus avisos deben ir en `THIRD-PARTY-NOTICES.txt`.

Los paquetes de contenido no viajan con el programa: son complementos opcionales en repositorios públicos aparte, que se instalan como `.paquete`. Todo su contenido es propio; no se tomó ninguna LUT, preajuste ni recurso de terceros.
