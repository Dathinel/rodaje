# Guía de Rodaje

Para quien descarga Rodaje y quiere editar. Cada página es corta y va con los menús y atajos tal como están en la app (estilo de teclado Rodaje, el de fábrica). Las capturas salen de la autoprueba del ejecutable publicado.

| Página | Qué cuenta |
|---|---|
| [Instalar](instalar.md) | Instalador, portable y completo; el aviso de SmartScreen; dónde guarda sus cosas |
| [Tu primer proyecto](primer-proyecto.md) | Importar, cortar, música, un título y exportar a vertical, paso a paso |
| [Edición](edicion.md) | Cortes, magnetismo, slip, velocidad y reversa, compuestos, tres y cuatro puntos, transiciones, marcadores, proyecto y recuperación |
| [Imagen](imagen.md) | Efectos, color (ruedas, curvas, LUT), antes y después, máscaras, croma, recorte, estabilizar, zonas seguras |
| [Seguimiento](seguimiento.md) | Seguir un punto, dos, cuatro esquinas o una región; corregir, suavizar y aplicar a otro clip, un anclaje de esquinas, una máscara, una zona o la estabilización |
| [Audio](audio.md) | Volumen, sonoridad LUFS, ecualizador y compresor, ducking, voz en off, silencios, ritmo, ruido |
| [Títulos y subtítulos](titulos-y-subtitulos.md) | Títulos sobre el visor, subtítulos automáticos, por palabra, karaoke, traducción |
| [IA local](ia-local.md) | Qué módulo hace qué, cómo se instala, GPU y VRAM |
| [Exportar](exportar.md) | Preajustes, Avanzado, varias versiones, la cola, rendimiento, verificación |
| [Rendimiento](rendimiento.md) | Qué esperar con NVIDIA, AMD, Intel y sin GPU: decodificación, proxies, exportación y copia directa |
| [Complementos](complementos.md) | Instalar, actualizar, desinstalar y crear los tuyos |
| [Atajos](atajos.md) | Teclado y ratón en los tres estilos, y cómo cambiarlos |
| [Personalización](personalizacion.md) | Tema, acento, escala, temas propios con editor, espacios de trabajo, proyecto nuevo y perfil exportable |
| [Preguntas frecuentes y solución de problemas](solucion-de-problemas.md) | La app no abre, un formato no se decodifica, la exportación falla, dónde están los registros, cómo informar |
