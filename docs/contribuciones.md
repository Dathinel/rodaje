# Contribuciones externas

Hoy Rodaje no acepta contribuciones externas: todo el código es de Daniel (Dathinel), que es el único titular y por eso puede elegir y cambiar la licencia (D-030, sustituida por D-032: GPLv3 con términos adicionales de atribución y permiso para complementos).

Si algún día se aceptan, antes del primer pull request ajeno hará falta un acuerdo de contribuidor. Con la GPLv3, una aportación entra bajo la misma licencia, pero sin acuerdo Daniel dejaría de poder hacer solo lo que hoy puede: cambiar de licencia, conceder licencias distintas de la GPLv3 o ampliar el permiso para complementos, y defender por sí solo los términos de atribución sobre ese código. La firma DCO de `CONTRIBUTING.md` no basta: solo certifica el origen del código, no concede esos derechos. El texto del acuerdo no se redacta aquí; queda en [`pendientes-legales.md`](pendientes-legales.md) para el abogado.
