# Contribuciones externas

Hoy Rodaje no acepta contribuciones externas: todo el código es de Daniel (Dathinel), que es el único titular y por eso puede elegir y cambiar la licencia (D-030).

Si algún día se aceptan, antes del primer pull request ajeno hará falta un acuerdo de contribuidor que permita a Daniel relicenciar el código aportado (por ejemplo, para dar permisos de uso comercial o cambiar de licencia). La firma DCO de `CONTRIBUTING.md` no basta: solo certifica el origen del código, no concede ese derecho. El texto del acuerdo no se redacta aquí; queda en [`pendientes-legales.md`](pendientes-legales.md) para el abogado.
